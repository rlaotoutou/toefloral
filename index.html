怎么打开和添加到主屏幕

iPhone / iPad

  1. 用 Safari 打开这个网址。
  2. 点底部的分享按钮（方框带向上箭头）。
  3. 往下滑，点 添加到主屏幕，再点右上角 添加。

用 iPhone 上的 Chrome 也可以：点地址栏右边的分享按钮，再选「添加到主屏幕」。

安卓手机

  1. 用 Chrome 打开这个网址。
  2. 点右上角 ⋮。
  3. 点 添加到主屏幕 或 安装应用，再确认。

三星浏览器：点底部菜单 → 添加页面到 → 主屏幕。华为、小米等自带浏览器：在菜单里找「添加到桌面」；找不到就换 Chrome。

Windows / Mac 电脑

  1. Chrome：点地址栏右边的安装图标，或者 ⋮ → 投放、保存和分享 → 将页面作为应用安装。
  2. Edge：点 ··· → 应用 → 将此网站作为应用安装。
  3. Mac 上的 Safari（macOS 14 及以上）：菜单栏「文件」→ 添加到程序坞。

用之前看一下

  • 你写的语料只存在这台设备、这个打开方式里。在 iPhone 上，Safari 网页和主屏幕图标是分开存的，所以建议先添加到主屏幕，以后都从图标打开再开始写。
  • 换设备或想搬数据：到「我的」点 导出备份，到新的地方点 导入备份。
  • 背诵时录音，第一次会问麦克风权限，请点 允许。iPhone 转不出文字的话，到「设置」里检查 Siri 和听写有没有打开。
  • 题库每周更新，联网打开就是最新的；没网时显示上次打开时的版本。
  • 邀请码只给你本人使用。邀请码被停用后，下次更新就打不开了，你写的语料仍保存在手机里。
